# 🪔 Diwali Sales Analysis

This project analyzes retail sales data during the Indian festival of Diwali. The goal is to explore customer purchasing behavior and identify trends that can help businesses improve marketing strategies, optimize inventory, and increase overall sales performance during festive seasons.

---

## 📊 Project Objective

* Understand customer demographics and purchasing patterns during Diwali.
* Analyze product categories and regions contributing most to sales.
* Generate visual insights using Python data analysis libraries.
* Gain hands-on experience with data cleaning, manipulation, and visualization.

---

## 🧰 Tools & Technologies Used

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **Jupyter Notebook**
* **CSV dataset** (`Diwali.csv`)
* **GitHub** (for version control and sharing)

---

## 📁 Dataset

The dataset contains sales transaction data including customer information such as:

* Gender
* Age Group
* City Tier
* Product Category
* Amount Spent

> Dataset used: `Diwali.csv`

---

## 📌 Key Steps in the Analysis

### 1. Data Import & Cleaning

* Loaded the dataset using `pandas.read_csv()`
* Removed null values and unnecessary columns

### 2. Data Exploration

* Reviewed top contributors by gender, age group, city, and product category
* Analyzed customer distribution using `value_counts()` and grouping

### 3. Data Visualization

Used `matplotlib` and `seaborn` to generate various plots:

* **Bar plots** comparing sales by gender and age group
* **Histograms** of amount spent
* **Pie charts** of city-tier distribution

### 4. Insights

* Female customers tend to purchase more in certain categories

## 📌 How to Run

1. Clone this repository:

   ```
   git clone https://github.com/Anusharijal/diwali-sales-analysis.git
   ```
2. Open the Jupyter Notebook:

   ```
   jupyter notebook Diwali_Sales.ipynb
   ```
3. Make sure `Diwali.csv` is in the same folder.
4. Run the cells to view analysis and visualizations.
